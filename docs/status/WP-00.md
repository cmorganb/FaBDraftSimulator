# WP-00: Repo, tooling, CI

**Status:** DONE
**Date:** 2026-09-14

## What was built

- Repo layout per plan section 4.3, using a **uv workspace** (root
  `pyproject.toml`, `[tool.uv.workspace] members = ["packages/*", "apps/*"]`)
  rather than a flat package - see
  `docs/decisions/ADR-0001-uv-workspace-and-deferred-web-tooling.md` for why,
  and for why `apps/web` is an empty placeholder this session.
- `packages/core`, `packages/agents`, `packages/exports`, `apps/api`,
  `apps/cli` each have their own `pyproject.toml` + package directory.
  Only `packages/core` has real code this session (`errors.py`); the rest
  are placeholders with a docstring pointing at the WP that owns them.
- `ruff` (lint + format), `mypy --strict` (scoped to `packages/core`),
  `pytest` (discovers `packages/{core,agents,exports}/tests`), and
  `pytest-cov` configured in the root `pyproject.toml`.
- `.pre-commit-config.yaml`: ruff, ruff-format, a local mypy-strict hook,
  and standard hygiene hooks.
- `.github/workflows/ci.yml`: a `python` job running ruff/mypy/pytest, the
  contracts-no-diff gate, the two purity greps (no `random.` outside
  `rng.py`; no `requests`/`httpx`/`anthropic`/`os.environ` inside
  `packages/core`), and a data gate (nothing under `data/sets/` committed
  except `.gitkeep`). A `web` job exists but is a documented no-op until
  `apps/web/package.json` shows up.
- `.gitignore`, root `README.md` (setup + IP/non-affiliation notice, full
  onboarding doc deferred to WP-25), `docs/status/INDEX.md` (all 27 WPs),
  `docs/status/BLOCKED.md` template, `docs/sources/README.md`.

## Interfaces exposed

- `fabdraft_core.errors.{FabDraftCoreError, DataIncompleteError,
  PackGenerationError}` - the error taxonomy every later WP raises into
  instead of guessing at missing data.
- Workspace dependency wiring: `fabdraft-agents`, `fabdraft-exports`,
  `apps/api`, `apps/cli` all declare a dependency on `fabdraft-core` already,
  so later WPs just add code, not plumbing.

## Decisions taken

- uv workspace over Poetry/flat layout (ADR-0001).
- `apps/web` deferred entirely - no `package.json` (ADR-0001), confirmed
  with the user before proceeding.
- mypy strict scope is `packages/core` only for now, matching the plan's own
  differential coverage requirement (core 90%, agents 80%) - will widen as
  `packages/agents` gains real code.
